# A 股桌面盯盘挂件 · 便携版（解压即用）

这个包**自带 Python 运行环境**，你不需要在电脑上装 Python、不需要配环境变量、
不需要联网下载依赖、也不需要管理员权限。解压后双击就能跑。

> 版本：v2.1.7

## 怎么用（三步）

1. 把整个 `astock-widget-v2.1.7-portable` 文件夹解压到任意位置
   （桌面、D 盘都行；**路径里尽量不要带中文和空格**，最稳）。
2. 双击里面的 `start.bat`。
3. 稍等几秒，右下角系统托盘会出现一个**折线图标**（涨红 / 跌绿 / 平灰），
   那就是挂件。左键点开看行情，右键可以退出。

第一次启动会自动生成 `stocks.json`（自选股配置，默认几只，可自行修改）
和 `logs/`（运行日志）。不需要手动准备任何东西。

## 和"源码版"有什么区别

|  | 便携版（本包） | 源码版（GitHub 克隆） |
| --- | --- | --- |
| 要不要装 Python | 不用，内置了 | 要自己装 3.10–3.14，再跑 install.bat |
| 要不要联网装依赖 | 不用 | 要（pip 装 PySide6） |
| 启动方式 | 双击 `start.bat` | 双击 `start.bat`（自动走 venv 分支） |
| 适合 | 普通用户、给朋友直接用 | 想看代码、想自己改的人 |

两个版本用的是**同一个 `start.bat`**：它先检查本目录有没有自带的
`py\pythonw.exe`，有就直接用（便携模式），没有才退回"建 venv + 装依赖"的老路子。
所以你拿到这个包，`start.bat` 会自动走便携模式。

## 数据放在哪

所有配置和日志都在**本文件夹内**，不写注册表、不乱放别处：

- `stocks.json` —— 你的自选股和设置。删掉它会恢复默认。
- `backups/` —— 配置的历史备份。
- `logs/run-YYYYMMDD.log` —— 每天一份运行日志，记录启动时间、断联次数、运行时长。
- `logs/crash-*.log` —— 只在程序异常时出现，里面有完整错误信息。

换电脑时，把这个文件夹整个拷走就行，配置和日志都带着走。

## 常见问题

**Q：双击 start.bat 没反应，托盘里没有图标？**

按这个顺序查：

1. 看本文件夹有没有生成 `logs/run-*.log`。有 `START` 那一行说明程序起了，
   只是窗口可能在别处；没有日志文件说明根本没启动。
2. 看 `logs/crash-*.log` 有没有。有的话把内容发我，里面有完整错误。
3. 确认解压路径**没有中文和空格**。

**Q：杀毒软件报毒？**

便携 Python 是官方 embeddable 包，内容只有 Python 解释器 + Qt（PySide6），
没有任何网络上传或后台行为。一般是误报，把整个文件夹加入杀软白名单即可。

**Q：想自己改代码 / 重新打包？**

包里的 `py/` 是官方 Python embeddable（约 10MB 的底座 + 预装好的 PySide6），
`widget.py` 等源码就在根目录，可以直接改。重新打包就是把整个文件夹再压成 zip。

有一个坑要注意：`py/python313._pth` 里那一行 `..` **不能删**——
它让挂件能找到同目录的源码模块（便携 Python 默认不会把程序所在目录加入
模块搜索路径，删了会报 `ModuleNotFoundError`）。

**Q：托盘图标和任务栏图标不一样？**

托盘（右下角）是涨跌幅折线，按涨跌变色；任务栏左侧那个"应用图标"改不了，
那是 Windows 从 Python 解释器读的，不影响使用。
